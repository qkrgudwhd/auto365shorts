Auto365Shorts 개인정보 처리방침 (Privacy Policy)

시행일: 2026년 11월 13일 · Effective date: November 13, 2026

1. 받는 정보

Auto365Shorts 는 사용자가 TikTok·YouTube 등의 공식 동의 화면에서 허락한 범위의 정보만 받습니다.

  • TikTok: 기본 프로필 정보(open_id, 표시 이름 — user.info.basic), 영상 올리기 권한(video.upload, video.publish)
  • YouTube: 영상 올리기·내 채널 이름 확인 권한
  • 각 서비스가 주는 액세스 토큰·갱신 토큰

사용자의 비밀번호는 받지도 저장하지도 않습니다.

2. 쓰는 곳

받은 정보는 사용자가 고른 영상을 사용자 본인 계정에 올리는 일과 연결된 계정 이름을 화면에 보여 주는 일에만 씁니다. 광고·분석·판매에 쓰지 않습니다.

3. 저장과 보안

  • 토큰은 사용자 컴퓨터 안에만 저장되며, 윈도 DPAPI 로 암호화합니다.
  • 프로그램 운영자나 다른 서버로 보내지 않습니다. 화면·기록 파일에도 토큰 값을 남기지 않습니다.

4. 제3자 제공

영상을 올리기 위해 해당 플랫폼(TikTok, YouTube)의 공식 API 로만 전송합니다. 그 밖의 제3자에게 제공하지 않습니다.

5. 보관 기간과 삭제

사용자가 프로그램의 계정 연결 탭에서 [지우기]를 누르면 저장된 토큰을 즉시 지웁니다. TikTok 설정 → 보안 → 앱 및 웹사이트 관리 권한에서도 언제든 허락을 거둘 수 있습니다.

6. 어린이

이 프로그램은 만 14세 미만을 대상으로 하지 않으며 그 정보를 일부러 받지 않습니다.

7. 변경과 문의

방침이 바뀌면 이 페이지에 날짜와 함께 게시합니다. 문의는 이 블로그의 댓글로 남겨 주세요.

English summary

Auto365Shorts only receives the data a user explicitly authorizes on the official TikTok or YouTube consent screen: basic profile info (open_id, display name), upload/publish permission, and the access/refresh tokens. Passwords are never collected. The data is used only to upload the user's chosen videos to the user's own account and to show which account is connected; it is not used for advertising, analytics or sale. Tokens are stored only on the user's own computer, encrypted with Windows DPAPI, and are never sent to the developer or any other server. Data is sent only to the platform's official API for uploading. Pressing [지우기] (Delete) in the app deletes stored tokens immediately, and users may revoke access in their TikTok/YouTube settings at any time. The app is not directed to children under 14.
